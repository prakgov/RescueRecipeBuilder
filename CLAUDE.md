# CLAUDE.md

## Git conventions

- Never add a Claude Code session link (`Claude-Session:` line or claude.ai/code session URL) to git commit messages.
- Follow Conventional Commits for every commit message: `<type>(<optional scope>): <summary>`, with types such as `feat`, `fix`, `docs`, `test`, `refactor`, `chore`, `ci`. Use the body to explain why.
